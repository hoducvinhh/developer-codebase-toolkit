# toolkit_common

Foundational library for `developer-code-toolkit`.

## Features
- Standardized CLI options & Exit Codes (0-4).
- Safe file walker (`SafeWalker`) with `.gitignore` integration and symlink guard.
- High-performance Secret Redactor (`SecretRedactor`).
- Unified Pydantic reporting schema with Terminal, JSON, Markdown, and SARIF v2.1.0 formatters.
- Robust config loader for YAML, TOML, and JSON.
